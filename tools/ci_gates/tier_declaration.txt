# THE DESELECTION DECLARATION — every test the default tier does NOT run.
#
# AUDIT-1 F-12. Gate 3c counts COLLECTED tests (`-m ''`, the whole tree). `make test` runs
# `-m "not integration and not slow"` and `make test.integration` runs `-m integration`, so a
# `slow`, `skip`, or host-true `skipif` marker removes a test from EVERY tier while the
# collected-test floor holds. `tests/model/conformance/` already refused exactly this for its
# own suite (`require_declared_tier_placement`); this file is that guard's tree-wide twin.
#
# ONE LINE PER (path, test, marker), sorted. `<module>` is a module-level `pytestmark`, which
# takes a whole file out in one line and is the form a reader scanning a function would miss.
# Adding a deselecting marker WITHOUT adding its line here reds gate 3c; REMOVING a marker
# without removing its line reds it too, because a stale declaration is a licence nobody is
# using and the next real one hides behind it.
#
# `integration` rows are NOT a hole: they run in `make test.integration`. They are declared
# because the census cannot tell which tier a marker moves a test INTO without being told, and
# because a test silently gaining `integration` leaves the default tier just as completely.
